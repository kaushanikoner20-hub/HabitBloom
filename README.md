# HabitBloom

A small, local-first habit tracker for building steady routines. It includes a daily checklist, streak counts, a monthly calendar, and weekly progress.

## Run

Open `index.html` in a browser. Habit data is saved in that browser's local storage; no install or server is needed.

## Use

- Check off a habit to record it for the selected day.
- Use the arrows beside the date to move between days, or choose a date in the calendar.
- Select `+ Add habit` to add a daily habit. The menu on a habit lets you remove it.
